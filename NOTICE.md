# Notices, Credits, and References

## Project credit

**Universal Security Skill — Engineered by Nakul.Kapdi.**

This repository contains original guidance, workflow design, templates, scripts, and documentation for a stack-aware, evidence-based security-review skill.

## Inspiration and upstream references

The initial concept was informed by an educational security prompt guide supplied during development. That guide grouped pre-launch review into secret leakage, personal-data flow, production readiness, complex authentication/payment logic, and attacker-perspective review. It referenced projects including Gitleaks, Bearer, ECC, and Trail of Bits Skills.

Universal Security Skill expands that concept into a separate, original workflow with stack discovery, threat modeling, applicability checks, evidence labels, verification requirements, severity/confidence handling, CI/supply-chain checks, AI-specific security checks, and reusable report templates.

This project also references established security standards and open-source tools including OWASP ASVS, OWASP API Security Top 10, OWASP Cheat Sheet Series, Gitleaks, CodeQL, Semgrep, OSV-Scanner, Trivy, and OWASP ZAP.
