# Support

For usage questions, installation help, false-positive discussions, or feature ideas, use GitHub Discussions if enabled. Otherwise, open a normal issue using the appropriate issue template.

For suspected vulnerabilities in this repository, **do not use public issues**. Follow `SECURITY.md`.

When asking for help, include your operating system, VS Code/Copilot or compatible agent environment, project stack, skill version, and the exact non-sensitive error output.
