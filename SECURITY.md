# Security Policy

Thank you for helping keep Universal Security Skill and its users safe.

## Supported versions

Security fixes are prioritized for the latest release on the default branch.

| Version | Supported |
| --- | --- |
| 1.1.x | Yes |
| 1.0.x | Best effort |
| < 1.0 | No |

## Reporting a vulnerability

**Do not open a public GitHub issue for a suspected vulnerability.**

Use GitHub's private vulnerability reporting / Security Advisory feature if it is enabled for this repository. If private reporting is not available, contact the repository maintainer through the contact method listed on the maintainer's GitHub profile and include only the minimum information needed to coordinate a private report.

Please include:

- affected version or commit
- impacted file, workflow, or instruction
- security impact
- minimal reproduction steps using a local or explicitly authorized target
- suggested mitigation, if known

Do not include live credentials, personal data, or exploit traffic against systems you do not own or have permission to test.

## Scope

Security issues in the skill instructions, bundled scripts, CI examples, or repository configuration are in scope. Vulnerabilities in third-party tools merely referenced by this project should be reported to their respective maintainers.

## Safe harbor

Good-faith research performed on your own systems or systems where you have explicit authorization is welcome. Do not perform destructive testing, privacy invasion, denial of service, or unauthorized access.
